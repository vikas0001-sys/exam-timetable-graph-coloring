# Exam Timetable Generation Using Graph Coloring

## Project Overview
This project generates an examination timetable using
Graph Coloring and the Backtracking Algorithm.

## Features
- Subject conflict detection
- Graph representation
- Backtracking algorithm
- Minimum examination slot calculation
- Automatic timetable generation

## Technologies Used
- Python 3
- Graph Theory
- Backtracking Algorithm

## How to Run
1. Download the Python source code.
2. Open Google Colab or Python IDE.
3. Upload the Python file.
4. Run the program.

## Algorithm
Graph Coloring using Backtracking.
